# Clipboard Manager

A local-only macOS clipboard history manager. It records what you copy (text, rich text, images,
links, files), shows it in a bottom-anchored glass panel, and copies an item back to the clipboard
when you pick it. It never pastes for you, never talks to the network, and never asks for
Accessibility permission.

- macOS 14 Sonoma and later (Liquid Glass via `NSGlassEffectView` on macOS 26, `NSVisualEffectView` before that)
- Swift / SwiftUI with AppKit for the panel, pasteboard, status item, and hot key
- Menu-bar-only agent app (`LSUIElement`), launches silently

## Building

Open `ClipboardManager.xcodeproj` in Xcode and run, or from a terminal:

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
xcodebuild -project ClipboardManager.xcodeproj -scheme ClipboardManager -configuration Debug -derivedDataPath build build
open build/Build/Products/Debug/ClipboardManager.app
```

Builds are ad-hoc signed (no team required). To install a Release build to `/Applications`:

```sh
Scripts/build-release.sh
```

**Launch at Login** only works from the `/Applications` copy: `SMAppService.mainApp` registers the
running bundle, so the menu refuses to enable it from a DerivedData build.

## Changing the keyboard shortcut

Edit one constant in `ClipboardManager/App/AppConfig.swift`:

```swift
static let toggleHotKey = HotKeyDefinition(keyCode: UInt32(kVK_ANSI_V), modifiers: [.control, .shift])
```

`keyCode` is any Carbon `kVK_*` virtual key code and `modifiers` any mix of `.command`, `.shift`,
`.option`, `.control`. The default is **⌃⇧V**. Rebuild to apply; the menu bar item shows the current binding.

## Using it

| Action | How |
| --- | --- |
| Toggle panel | shortcut, or left-click the menu bar icon |
| Dismiss | shortcut again, Esc, click outside, or pick an item |
| Pick an item | click a card, or ←/→ then Return |
| Delete an item | hover → trash, or select with arrows and press Delete |
| Pin / unpin | hover → pin |
| Filter | "Filter" button, top-right (resets to All each time the panel opens) |
| Settings | right-click (or control-click) the menu bar icon |

Pinned items sit at the far left, separated by a divider, most recently pinned first. Everything else
is newest first; re-copying something moves it to the front instead of creating a second card.

## Storage

- Database: `~/Library/Application Support/ClipboardManager/history.sqlite`
- Blobs (images, thumbnails, RTF): `~/Library/Application Support/ClipboardManager/blobs/`
- Unpinned items expire after 7 days (checked at launch and hourly). Pinned items never expire.
- Global cap of 500 MB; oldest unpinned items are evicted first.
- Images are downscaled to a 2048 px longest edge and stored as JPEG (quality 0.7) or PNG when they
  contain real transparency. Items over 10 MB after compression are skipped. Cards use 256 px thumbnails.

## Privacy rules

Pasteboard items flagged `org.nspasteboard.ConcealedType` (password managers),
`org.nspasteboard.TransientType`, or `org.nspasteboard.AutoGeneratedType` are never stored.
Pausing from the menu suspends the poll timer entirely.

## Layout

```
ClipboardManager/
  App/        AppDelegate (entry point, wiring), AppConfig (all tunables incl. shortcut)
  MenuBar/    NSStatusItem, menu, launch-at-login
  Hotkey/     Carbon RegisterEventHotKey wrapper
  Clipboard/  polling monitor, pasteboard reader/writer, capture processor
  Storage/    SQLite wrapper, HistoryStore (dedupe + retention), BlobStore, ClipItem
  Images/     compression, downscaling, thumbnails
  Panel/      non-activating NSPanel, glass background, controller, SwiftUI panel + cards, hover preview
  Support/    caches, formatters, code heuristic
Supporting/Info.plist    LSUIElement agent app
Scripts/                 build-release.sh, debug-command.swift
```
